# Public History Provenance

This repository begins with a clean public root commit created from a locally reviewed, privacy-remediated Agent Workbench source snapshot.

Earlier development history and tags are retained offline and are intentionally not published because reachable historical objects included machine-specific paths and invalidated release evidence. They were not rewritten into the public history.

The clean public root preserves the current product source, build configuration, tests, and current public documentation. It intentionally omits private execution reports, local planning state, invalidated artifacts, and historical release-candidate evidence.

Release artifacts must be rebuilt from a clean clone of the public root. Artifact checksums and artifact-to-commit mapping belong to the corresponding release review record.
